# Memory Vault System

A secure full-stack web application that allows users to store, organize, and manage personal notes, memories, and important information in a centralized digital vault.


# Features

- Create, Read, Update, Delete (CRUD) memories/notes
- Categorize and organize memories
- Search functionality for quick access
- Data stored securely in MongoDB
- Responsive and clean UI


# Tech Stack

# Frontend:
- React.js (jsx)
- CSS
- JavaScript
- Axios

# Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose
